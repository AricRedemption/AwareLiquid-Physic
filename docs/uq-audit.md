## 1. 工具口径审计(benchmarks/probabilistic_eval.py,118 行)

ProbabilisticLiquidModel 对隐藏刚度 ω 推断**分布 (mu, logvar)**
(VAE 式后验),采样 n_samples=20 得 ensemble 辛滚出。输出指标:
- `ensemble_mean_mse`:ensemble 均值的 rollout MSE(点预测);
- `ensemble_spread`:成员对均值的 RMS 偏差(**标量聚合**,不确定性幅值);
- `context_logvar_mean`:推断上下文方差均值(标量)。

**有的**:方差语义(spread + logvar)——不是纯点估计工具。
**没有的**:① 逐样本/逐时刻区间或分位数 ⇒ **coverage 不可计算**;
② 任何校准判据(coverage error / CRPS / z-score 检验);③ 逐样本
(mu, logvar) 与真值 ω 的配对输出。

## 2. 产物代际审计(重要发现)

## 5. 校准协议升级草案(云跑候选,预注册)

+ 推理,对每个 eval 样本算 **z = (mu − ω_true)/exp(0.5·logvar)**:

  否则如实记 miscalibration(过度/欠自信方向)。
