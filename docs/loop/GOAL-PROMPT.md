# GOAL-PROMPT — 自循环马拉松提示词(正本,随 AMENDMENTS 演化)

> **会话角色(AMM-011)**:粘贴本文件的是**执行会话**——按 GOALS.md 程序计数器
> 迭代:清欠账→队列目标→(判据满足时)收口。体系设计/治理改动在**独立设计
> 会话**进行(AMENDMENTS 提案制);设计会话不执行研究实验,执行会话不改机制。

> 用法:在 AwareLiquid-Physic 工作区**新开一个 ZCode 会话**,整段粘贴。
> 第一行必须是 `/goal` 开头——各家 harness 都认这个前缀作为目标声明。
> 本文件由 AMENDMENTS 提案制维护;改这里的规则 = 改循环自身,走提案。

```text
/goal 按 docs/loop/GOALS.md 的 goal_queue 持续自循环迭代本项目:每轮先跑 ./scripts/goal_check 校验顶部目标——NOT-Achieved 则对该目标迭代一轮,ACHIEVED 则弹出晋升下一个,QUEUE-EMPTY 则**先查 docs/loop/DEBT-LEDGER.md(AMM-009 欠账优先):有 open 欠账先清欠**(按台账顺序 T1/T2 本机执行并验收),无欠账才进入**经验蒸馏轮**(社区/论文扫描:找有效经验与前沿方向,每条按"出处+适用条件+验证状态"入库——操作类固化进 PLAYBOOK、工具类实现进 TOOLS、**方向类必须转换成 GOALS 队列目标**;本轮交付=≥1 个新队列目标,仅归档不入队不算完成;连续 2 轮蒸馏产出全为 [坐标] 类 ⇒ 按停止规则收口);直到你手动停止或触发收口判据,中途不停。

迭代纪律:
- 启动自检(防双马拉松,第一优先):先跑 `./scripts/marathon_guard`——exit 1 ⇒ 已有活马拉松(锁龄 <100 分钟),本次转为"仅确认状态并结束";exit 0 ⇒ 放行进入循环体(循环内每轮 goal_check 自动刷新 .loop-lock 存活心跳;收尾时删除它)。绝不并行第二马拉松。
- 算力闸门 v3.1(AMM-008+010,硬,每轮动手前必过)分四档:**T0 零算力**(判读/文档/文献扫描/秒级探针,默认档,每条 <10min);**T1 直跑档**(预计 ≤30min/条,每轮算力合计 ≤60min:小样本训练/推理/评测**当轮串行直接做,跑完当轮判读**——"能做先做,快速获取结果优先");**T2 后台档**(预计 30–60min:预注册 PRD §19 → `./scripts/probe_run T2 <est_min> -- <命令>` 护栏后台[线程⌊0.6×核⌋+nice 15+PROBE_TIER 溯源,同一时刻仅 1 个] → 马拉松继续零算力轮,次心跳机械验收);**T3 云档**(>60min 或全量/多 seed 终局——**Probe-First 硬准入:登记欠账/开 PR 前必须先有本机 T1/T2 探针结果随附**,管线校验+时长实测+方向预筛三合一,无探针结果的 T3 台账不予登记)。**T1/T2 结论只解锁路由决策与假设筛选,不得单独支撑 N1 终局声明**——终局声明必须 T3 或隐藏卷一次性复验;结果 JSON meta 必带 exec_tier/tier_est_min/threads/nice。
- 资源护栏(AMM-008 硬约束,护机优先于任何实验):本机 CPU 线程上限 ⌊0.6×逻辑核⌋(probe_run 自动设置,M2 Max 12 核→7 线程,峰值占用 ~58%,红线 70% 之下)+ nice -n 15 降优先级;风扇满速/机器发烫/卡顿 ⇒ 立即人工中止实验;不与其他重负载并发;T2 不做硬超时(防误杀训练),墙钟膨胀 ~1.4–1.7x 属预期,资源占用恒低不违宪法"预计 ≤1h"护机本意。
- 吞吐优先:每轮时间预算向"方向迭代"倾斜——一个心跳尽量产出一个非算力型成果(设计文档/探针结论/代码+测试/判读报告)。
- 每次迭代:预注册判负标准先行(写进 docs/PRD.md §19)→ pytest 全绿 + benchmarks/audit_results.py --check 全过 → 原子提交 push 到 fork 的当前方向分支(dir/<slug>;集成线 wave/loop 由方向毕业合并推进)。
- 收尾时间由你决定:粘贴时可以附加说明(如"跑到今晚 23 点收尾");不指定则持续迭代,直到你手动停止(说停/关闭会话)。收尾动作固定:在 PRD §19 写收尾记录,并按 docs/loop/RSI-INDEX.md 计算当夜指数(K/E/T/D/T+/A+复合)入账 → 删除 .loop-lock(如存在)→ 停止本会话。
- 上下文过长或单目标卡住超过两轮:把状态快照进 docs/loop/GOALS.md 后结束本轮;重开新会话粘贴本 prompt 即无缝续跑。
- 训练↔方向平衡(AMM-012):滑动 10 轮窗口内**证据轮(T1/T2 执行+判读或 T0 数字判读)占比 ≥30%**,<20% ⇒ 冻结蒸馏直至补证据轮;**已入队未执行的 [行动] 目标 WIP ≤2**,WIP 满时蒸馏只产 [坐标] 不产 [行动];**任何 T1/T2 判读完的下一心跳=消化轮**(判读回填→分流表→条件重入口处置),禁止直接开新蒸馏——训练结论先变路由决策,再挖新方向。
- 需要人决策的事:GOALS.md 的 state 改 BLOCKED-HUMAN 并写明问题,停止。
- 每轮收尾强制回写:至少一条经验/教训/坑到 docs/loop/PLAYBOOK.md(没有坑就写一条被验证有效的做法)——大厂"抓问题→学经验→升级"的最小落地。
- 结论类目标(得出"X 比 Y 好"类定量结论)的交付 PR 必须包含隐藏卷终跑指令(用未消耗 seed 复验主结论);隐藏结果回传并通过判据后,目标才算达成弹出——防被单次抽签骗。
- 新踩的坑回写 docs/loop/PLAYBOOK.md;新工具回写 docs/loop/TOOLS.md;对循环自身的改进提案写 docs/loop/AMENDMENTS.md(不自行改本 prompt 与宪法)。

纪律以工作区 AGENTS.md 为准。分支模型(AMM-003/005):`wave/loop` = 集成线(所有已验证成果汇入);**每个新方向自 wave/loop 切 `dir/<slug>` 分支,单因子迭代到底**——方向 done_condition 达成且判据/隐藏验证通过 → 开 PR(dir/<slug> → 集成线;origin/master 追平后可直接开到 master),合并仍人工;新方向 = 新分支 = 新 PR。不改写历史判定行;不 push master/origin;不提交 .pt;隐藏集终跑用 ./scripts/hidden_check(seed 999 已退役,998 递减)。
停止规则(AMM-007,修订 AMM-006):**欠账优先**——docs/loop/DEBT-LEDGER.md 有 open 欠账 ⇒ 心跳优先消化(T1/T2 本机或升级人裁),禁止新蒸馏族扩池;"先把预注册的做完,再挖新方向"。**收口判据 S1–S4**(任一满足即收口为 state: IDLE,写收尾记录+RSI 入账;IDLE≠项目终止,保留重入口:结果回传/用户新指令/新欠账,重入即 RUNNING):S1 队列空且连续 2 个蒸馏轮产出全为 [坐标] 类(无 [行动] 转目标);S2 最近 10 条入库条目未消化比例 >70% 或台账 IR>5;S3 RSI_loop 连续 2 收尾夜 <0.5 且 T̂ 当期未触发;S4 用户手动停(不变)。"穷尽≠停止"精神有限保留:同 query 族换法重试 ≤3 次,超限按当期判据收口不无限重试;蒸馏条目仍必须转换成队列目标或标注"不适用+理由"。open 欠账债龄 >5 心跳轮且无本机档位 ⇒ 升级 BLOCKED-HUMAN 请人三选一(本机批跑/云 PR/作废)。
```

**需要算力的目标的一生**(详见 PRD §19 各轮协议):发现(本地探针)→ 预注册验收标准(本地文档)→ PR 交付算力(含隐藏卷终跑指令)→ 结果回传 → 机械验收 → 毕业弹出/如实记负。
