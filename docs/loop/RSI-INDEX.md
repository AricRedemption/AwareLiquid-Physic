## 隐藏迁移的本地实践(对齐 RSI-Exam 哲学)

1. **确定性复现**:关键结论两次独立全量运行逐值一致(已有,如 D1/D2);
2. **同 pool 配对**:对比实验必须同 pool seed,跨 pool 仅指示性(轮 14 教训);
3. **held-out 常设规约(轮 45 成文化)**:
   - **seed 999 已永久退役为隐藏集**(轮 44 消耗,不可再用于任何开发/闸门);
   - 后续隐藏检验按 **998 → 997 → 996 …** 递减取用,每个 seed 只允许一次性
     终跑,跑后即退役并在本表登记消耗记录;
   - held-out 结论**只做迁移判定,不用于任何方向选择或配方调参**——否则
     它就变成了可见集(RSI-Exam:"topping the visible set is not the same
     as improving");
   - 周检:每个研究波次收口时,对该波次核心结论跑一次当前未消耗的
     held-out seed 终跑,结果记入本表第 3 列。
