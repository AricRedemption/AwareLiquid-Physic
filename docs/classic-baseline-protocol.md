> 公平性三声明(仿 tsfm-baseline-protocol 先例,与数字同表出现):

## 公平性三声明

1. **数据体制差异**:本仓仿真数据无观测噪声(datasets 无噪声项,轮 71
   判读),线性振子 + 已知模型形式恰是经典估计的**最佳域**——经典臂
   (结构利用型:已知谐波形式,数据驱动估参)在此域是上界参照,
   不代表含噪/非线性域的相对强弱。
2. **非公平基线定位**:类别跨界参考(经典 LS vs 神经结构化),非同台
   排名;经典臂利用了"模型形式已知"这一先验,与本仓方法共享该先验
   (哈密顿方程+辛积分器),差异在**参数估计机制**(闭式/稀疏回归 vs
   液基推断链)。
3. **预期用途**:读者参照——任一结果都有信息量,均不构成排名结论;
   本仓价值主张锚结构性质轴(守恒由构造/辛滚出/能量漂移)与 M2 场线
   (P3 已收口),**不锚线性振子单参数估计精度**(D6 已判单参数信息层
   非瓶颈)。

## 协议

- 同池:`gen_spring(n_train+128, steps=160, dt=0.1, ω∈[0.7,1.8], seed
  s∈{0,1,2})` 尾 128 条 held-out;2 池(n_train∈{32,64})×3 seeds
  ×128 轨 = 768 轨,与 D-2 TSFM 协议逐轨同池。
- 观测:q-only(t_obs=24 前 25 点);p 不直接给经典臂(FD 污染边界),
  由**解析 (A,B) 最小二乘**在 ω̂ 给定下重构末态 (q_T, p_T)(谱精度,
  避开 FD 边界 O(dt) 误差)。
- 两臂:① LSQ-ω̂ = 中心差分加速度 + 过原点线性 LS(q̈=-ω²q);②
  STLSQ = 多项式库 [q, q̇, q², q·q̇, q̇²] 顺序阈值回归(自实现,不引
  pysindy,零依赖)。
- 滚出:ω̂ 下 velocity-Verlet k=100(dt=0.1),MSE 对 q 真值。
- 命令:`./scripts/probe_run T1 5 -- .venv/bin/python
  benchmarks/classic_baseline_eval.py`;产物
  `benchmarks/physics_out_v02/classic_baseline/`(audit 过)。
- 判负标准:见 PRD §19 轮 98 预注册(ω̂ 相对误差>5% ⇒ 如实标注/
  STLSQ 不恢复 ⇒ 降级单臂/环境不可行 ⇒ 协议登记)。
