# DH-DESIGN — 耗散扩展设计文档(轮 74,2026-09-19)

> 目标:给 `HamiltonianHead` 一个**默认关、R≡0 逐位等价**的耗散槽位,
> 使"能量守恒由构造"(P0-3)的架构在需要时能表达真实世界的能量衰减,
> 同时不改变任何既有结论/检查点/数值行为。文献坐标:scan §15
> (D-HNN / Port-HNN);预注册判负标准:PRD §19 轮 73。
> **本设计不含训练**——全部验证为闭式/结构探针(tests/test_dissipation.py)。

## 1. 动机与边界

当前头 H(q,p)=T(p)+V(q|ctx) 经 velocity-Verlet 滚出,能量守恒由构造
(P0-3,有界 O(dt²) 漂移)。这在本仓全部保守基准(弹簧族/波场,轮 71
确认无噪)上是**优点**;但对"真实系统"叙事是显式边界:任何带摩擦/阻尼/
耗散的物理都无法表达。N1 Related Work 必答此问。

## 2. 文献两形态对照(scan §15)

| | D-HNN(Sosanya & Greydanus 2022) | Port-HNN(Desai et al. 2021 PRE) |
|---|---|---|
| 形态 | ṗ = −∇qH − ∇pR,R 自由 NN | ẋ = (J(x)−R(x))∇H,J 反对称,R 半正定 |
| 单调保证 | 无构造保证(R 任意) | dH/dt = −∇HᵀR∇H ≤ 0 **由构造** |
| 实现厚度 | 最薄(加一项力) | 改动面大(结构重构) |
| 哲学 | 分离建模 | 硬约束,与本仓 P0-3 同构 |

## 3. 选型:port 风味的 PSD 阻尼场(D-HNN 厚度)

`rayleigh=True` 时增加阻尼场网络 G: dim→dim,**γ(p) = softplus(G(p)) ≥ 0
逐坐标**,阻尼力:

    F_d(p) = −γ(p) ⊙ ∇pT(p)          (ṗ = −∇qH + F_d)

**单调性由构造**:dH/dt = ∇pH·F_d = −Σᵢγᵢ(∇pT)ᵢ² ≤ 0。
取 D-HNN 的实现厚度(一个小 MLP + softplus),取 port-HNN 的构造性
保证(耗散 = PSD 场作用于能量梯度流,不是自由力)——两形态优点的
最小交集。γ 退化为常数时即线性阻尼 R = ½γ‖p‖² 的推广。

## 4. 积分器:damped 分裂(kick 中加力)

velocity-Verlet 的两个 kick 由 ṗ = −∇qH + F_d 驱动(F_d 在 kick 起点
p 与半步 p_half 各评估一次);drift 不变。连续极限单调;离散为
O(dt²) 分裂误差——**探针实测此格式对随机非线性 T,V 逐步严格单调**
(见 §6)。

## 5. 默认关语义(判据 A)

`rayleigh: bool = False` 默认参数;False 时:
- 不创建 G(`state_dict` 无 G 键 → 既有检查点严格兼容);
- step 走**未改动的保守代码路径**(flag 短路,无任何新浮点运算)
  → 与扩展前实现**逐位一致**(test_a 以手写 kick-drift-kick 参照
  `torch.equal` 验证,16 步 rollout 逐位相等)。

## 6. 判据 B 实测(探针轮 74,全部秒级、seed 固定)

- **B1 闭式阻尼谐振子**(手写同分裂格式,T=½p², V=½q², R=½γp²,
  γ=0.3, dt=0.005, 4000 步):对数衰减斜率 **−0.30103**(解析 −0.3,
  误差 0.34%);逐步能量变化 max **+1.5e-8**(浮点级单调);
  H_end/H0 = 2.9e-3 ≈ e^{−γT}。
- **B2 头级结构单调性**(随机 T,V,γ 冻结 0.8,dt=0.02/0.01,600/
  1200 步):每步能量变化 max **−1.8e-5 / −9.1e-6**(两种步长下
  **严格单调,零正注入**);逐项衰减 H_end/H0 ∈ [0.187, 0.633];
  **γ≈0 对照臂逐项 H_end/H0 = 1.000**(辛有界守恒)——衰减可归因于
  阻尼通道而非漂移;两步长端点一致(格式收敛)。

### 6.1 判负边缘事件(如实入档)

首跑探针**抓到 step 实现的符号反接**(F_d 被写进 `-0.5dt(∇V + F_d)`
括号,实际效果 +0.5dt·γ∇T = 反阻尼):实测每步 ΔH 严格为正、随 dt
线性(平均 +8.3e-5 @dt=0.02)。修复(改为 `+0.5dt·F_d`)后复跑全绿。
**判据 B 的"单调"断言按设计捕获了该 bug**——探针有效性当场自证。
修复后无任何判负触发:**判据 A ✓,判据 B ✓(B1 误差 0.34%,B2 零注入)。**

边界注记:衰减幅度依赖 |∇T| 沿轨迹的取值——随机 tanh 景观的近平坦区
(|q̇|→0)物理性"冻结",衰减停在 >0 平台(对照臂归因判据即为此设,
不用"衰减到 e^{−γT}"这种对一般 T 无意义的强断言)。

## 7. 与 T 偶(R1b)的结构交互

Rayleigh 力是 p 奇函数(γ∇pT 在 T 偶参数化下)⇒ 耗散系统天然时间反演
不可逆:回程一致性冒烟仅对保守部分(γ≡0)适用。守恒部分的 T 偶
参数化(R1b 硬形态)与耗散通道**正交、可叠加**;若 R1b 落地为
T(p)=MLP(p⊙p),耗散槽位不需任何改动。

## 8. 范围与未来

- **范围:仅 `HamiltonianHead`(M1 点力学头)**。FiLM/Operator/2d/
  TimeConditioned/Nonseparable 头**不实现**耗散槽位;若未来需要,
  按同模式(PSD 阻尼场 + kick 加力)逐头迁移,迁移前先扩探针。
- 未做:训练/拟合验证(算力闸门外,且无保守+耗散混合基准任务);
  γ(p) 的可解释性探针(未来线)。
- 结论类声明:**本设计不产生"X 比 Y 好"定量结论**,属结构预留位,
  隐藏集条款不适用。
