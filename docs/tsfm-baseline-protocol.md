# TSFM-BASELINE — 时间序列基础模型零样本参考基线协议(轮 82,2026-09-19)

> 目的:评审"对比过基础模型吗"的合规响应——把 Chronos/TimesFM
> 零样本预测作为**类别跨界参考基线**登记为云跑候选。素材:scan §19
> (轮 81);判负标准:PRD §19 轮 81。本机不跑(算力闸门)。

## 1. 协议定义

- **模型**:Chronos(亚马逊,数值 token 化)与 TimesFM(Decoder-only),
  各取官方零样本权重,不做任何微调。
- **任务**:M1 弹簧单轨迹 q(t) 单变量多步预测——给观测前缀
  (t_obs=24 步),要求模型递归外推 k=100 步;同一批测试起点与
  真值序列,与 prefix/semigroup 臂同池。
- **输出对齐**:TSFM 输出为 q 的预测序列(标量通道);真 p 通道
  不参与(TSFM 无法利用动量通道——这正是接口轴差异的体现,见 §2)。
- **判据**:k100 rollout MSE 同表呈现(与既有 eval_ks 口径一致,
  阈值口径同 §轮 80 VPT 文档);3 seeds;点估计+seed 区间。
- **云跑命令草案**:官方权重加载 + 推理-only 脚本(待 PR 化时给出
  完整可执行产物);预计时长 ~15 分钟(GPU/CPU 推理)。

## 2. 公平性三声明(必须与数字同表出现)

1. **数据体制差异**:TSFM 靠跨域海量预训练;本仓线是小样本
   (n=32..512)+ 情境推断。两者优化的是不同体制下的不同问题。
2. **非公平基线定位**:本对照是**类别跨界参考**(category-crossing
   reference),不是同台公平排名——TSFM 无结构保证(无守恒/辛),
   本仓线的结构收益(能量漂移等)不在 TSFM 的能力空间内。
3. **预期用途**:读者参照(若零样本 TSFM 已能接近,则结构化线的
   增益必须重新论证;若 TSFM 大幅落后,则说明物理状态序列在
   TSFM 分布外)——**任一结果都有信息量,都不构成排名结论**。

## 3. 预期行为与解读框架(预注册,非预言)

- 弹簧 q(t) 是光滑近周期序列,属 TSFM 训练分布的"友好区";
  短视距(k≤10)TSFM 可能不差。长视距(k=100)无结构约束的
  复合误差与相位漂移预期主导——此为预期,非判定;判定以实测为准。
- 结构化线的差异轴(接口:p 通道/守恒/辛)在 TSFM 上不可用,
  这是 §19.1 接口轴的实证注脚,写进讨论节而非结论节。
